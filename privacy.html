개인정보처리방침

최종 수정일: 2026-09-28

이 방침은 "소름 돋는 세상" 콘텐츠 자동화 도구(이하 "본 도구")가 데이터를 어떻게 다루는지 설명합니다. 본 도구는 채널 운영자 본인이 자신의 YouTube 및 Instagram 채널에 영상을 업로드·게시·관리하기 위해서만 사용하는 개인용 자동화 도구입니다.

1. 수집·사용하는 정보

  • 본 도구는 운영자 본인의 Google/YouTube 계정에 대한 OAuth 접근 권한(영상 업로드·수정·댓글)을 사용합니다.
  • 이 권한은 오직 운영자 본인 채널에 콘텐츠를 발행·관리하는 목적으로만 쓰입니다.
  • 본 도구는 제3자 이용자의 개인정보를 수집하지 않습니다.

2. 정보의 저장

  • 인증 토큰은 발행 자동화를 위해 안전한 비공개 저장소(GitHub Actions Secrets)에만 보관됩니다.
  • 토큰은 외부에 공유·판매되지 않습니다.

3. 정보의 공유

본 도구는 어떤 데이터도 제3자와 공유하지 않으며, Google API로 받은 정보는 Google API Services User Data Policy(제한 사용 요건 포함)를 준수하여 사용합니다.

4. 권한 철회

운영자는 언제든지 Google 계정 권한 페이지에서 본 도구의 접근 권한을 철회할 수 있습니다.
